## How to Run the Notebook

Follow these steps to run the `e1351028.ipynb` notebook directly in VS Code or Jupyter Notebook.

### 1. Place the Dataset in the Root Folder
Before opening the notebook, ensure the dataset files are placed in the exact same folder as `e1351028.ipynb`. Ensure these three files are present:
- `train.csv`
- `test.csv`
- `txs_edgelist.csv`

### 2. Install Dependencies
Install all required libraries by running the cell in the notebook or using pip:
```bash
pip install -r requirements.txt
```

### 3. Run the Notebook
1. Open `e1351028.ipynb` using **VS Code** or **Jupyter Notebook**.
2. Click "Run All" in VS Code to run the whole notebook. 
3. The notebook will process the data and generate the final `e1351028.csv` predictions in the same folder.
